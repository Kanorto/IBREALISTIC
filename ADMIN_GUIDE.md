## Введение

IBRealistic состоит из двух компонентов:
- **IBRealistic мод** (клиент, Fabric) — физический движок, рендеринг, телеметрия
- **TimingSystem плагин** (сервер, Paper) — управление режимами, гонками, экономикой, треками

Для полноценной работы требуются оба компонента. Мод работает на MC 1.20.4, 1.21 и 1.21.3.

## Установка

### Серверная часть (TimingSystem)
1. Скачайте `TimingSystem-3.2-x.x.x.jar` из [Releases](https://github.com/Kanorto/IBREALISTIC/releases)
2. Поместите в папку `plugins/` вашего Paper сервера
3. Перезапустите сервер
4. Настройте `plugins/TimingSystem/config.yml`

### Клиентская часть (IBRealistic мод)
1. Установите [Fabric Loader](https://fabricmc.net/) для вашей версии MC
2. Установите [OpenBoatUtils](https://github.com/o7-Fire/OpenBoatUtils) мод (зависимость)
3. Скачайте `IBRealistic-x.x.x_MCversion.jar` из Releases
4. Поместите в папку `.minecraft/mods/`

## Режимы (Modes)

Режимы — это предустановленные конфигурации физики для лодок. Задаются через TimingSystem.

| ID | Режим | Описание | Тип машины | Привод |
|----|-------|----------|------------|--------|
| 25 | `REALISTIC` | Базовый реалистичный | WRC_CAR | AWD |
| 26 | `REALISTIC_WRC` | Современный WRC | WRC_CAR | AWD |
| 27 | `REALISTIC_GROUP_B` | Группа B | GROUP_B | RWD |
| 28 | `REALISTIC_CLASSIC` | Классическое ралли | CLASSIC_RALLY | RWD |
| 29 | `REALISTIC_LIGHTWEIGHT` | Лёгкая машина | LIGHTWEIGHT | FWD |
| 30 | `REALISTIC_TRUCK` | Раллийный грузовик | TRUCK | AWD |
| 31 | `REALISTIC_ALLTERRAIN` | Вездеход | WRC_CAR | AWD |

Все режимы включают: `airControl=true`, `fallDamage=false`, `stepSize=1.25`.
`REALISTIC_ALLTERRAIN` дополнительно включает `canStepWhileFalling=true`.

## Команды настройки режимов

### Создание и управление (bume = Boat Utils Mode Edit)

```
/ts bume new <имя>             — создать новый режим
/ts bume select <имя>          — выбрать режим для редактирования
/ts bume save                  — сохранить изменения
/ts bume info                  — показать текущие настройки
```

### Параметры физики

```
/ts bume set realisticPhysics true|false     — вкл/выкл реалистичную физику
/ts bume set vehicleType <0-4>               — тип машины (0=WRC, 1=GROUP_B, 2=CLASSIC, 3=LIGHTWEIGHT, 4=TRUCK)
/ts bume set vehicleDrivetrain RWD|FWD|AWD   — тип привода
/ts bume set vehicleMass <кг>                — масса (100–5000)
/ts bume set vehicleWheelbase <м>            — колёсная база (1–5)
/ts bume set vehicleCgHeight <м>             — высота центра тяжести (0.1–2)
/ts bume set vehicleTrackWidth <м>           — ширина колеи
/ts bume set vehicleMaxSteering <рад>        — макс. угол руля (0.1–1.2)
/ts bume set vehicleSteeringSpeed <рад/с>    — скорость вращения руля (0.5–10)
/ts bume set vehicleBrakingForce <Н>         — тормозная сила (1000–20000)
/ts bume set vehicleEngineForce <Н>          — тяговая сила (1000–20000)
/ts bume set vehicleDrag <коэф>             — аэродинамическое сопротивление
/ts bume set vehicleBrakeBias <0-1>          — распределение тормозов (1.0=всё на перед)
/ts bume set vehicleSubsteps <1-10>          — подшаги на тик (больше = стабильнее)
/ts bume set vehicleFrontWeightBias <0.3-0.7> — развесовка (0.55 = 55% перед)
/ts bume set steeringReturnRate <рад/с>      — скорость возврата руля (0=откл.)
/ts bume set damageEnabled true|false         — включить систему поломок
```

### Поверхности

```
/ts bume addsurfacetype <тип> <блок>     — привязать блок к поверхности
/ts bume set defaultSurfaceType <тип>    — поверхность по умолчанию
/ts bume clearsurfacetypes               — очистить все привязки
```

Типы поверхностей: `ASPHALT_DRY`, `ASPHALT_WET`, `CONCRETE`, `BRICK`, `METAL`, `TERRACOTTA`, `GRAVEL`, `WOOD`, `NETHER`, `DIRT`, `SAND`, `VEGETATION`, `GLASS`, `SNOW`, `MUD`, `WOOL`, `ICE`, `BLUE_ICE`

### Пресеты компонентов

```
/ts bume set tirePreset <имя>             — пресет шин
/ts bume set enginePreset <имя>           — пресет двигателя
/ts bume set bodyPreset <имя>             — пресет кузова
/ts bume set suspensionPreset <имя>       — пресет подвески
/ts bume set steeringPreset <имя>         — пресет рулевого
/ts bume set brakePreset <имя>            — пресет тормозов
/ts bume set weightDistPreset <имя>       — пресет развесовки
```

## Настройки треков

### Погода для трека

```
/te weather CLEAR|RAIN|HEAVY_RAIN|SNOW|FOG   — установить погоду трека
```

| Погода | Модификатор сцепления | Описание |
|--------|----------------------|----------|
| `CLEAR` | ×1.0 | Ясно (по умолчанию) |
| `RAIN` | ×0.70 | Дождь |
| `HEAVY_RAIN` | ×0.50 | Ливень |
| `SNOW` | ×0.40 | Снег |
| `FOG` | ×0.95 | Туман (сниженная видимость) |

### Время суток

```
/te time DAWN|NOON|SUNSET|NIGHT|MIDNIGHT   — пресеты времени
/te time <0-24000>                         — произвольные тики
```

| Пресет | Тики | Описание |
|--------|------|----------|
| `DAWN` | 0 | Рассвет |
| `NOON` | 6000 | Полдень |
| `SUNSET` | 12000 | Закат |
| `NIGHT` | 18000 | Ночь |
| `MIDNIGHT` | 13000 | Полночь |

### Динамическая погода

```
/te dynamicweather enable|disable   — включить/выключить смену погоды на треке
```

При включении погода циклически меняется: CLEAR → RAIN → HEAVY_RAIN → RAIN → CLEAR. Интервал настраивается в `config.yml` (`dynamic_weather.change_interval_minutes`).

### Сложность трека

```
/te difficulty <1-5>   — установить сложность трека (влияет на награды)
```

| Сложность | Звёзды | Множитель монет | Множитель XP |
|-----------|--------|-----------------|--------------|
| 1 | ★☆☆☆☆ Easy | ×1.0 | ×1.0 |
| 2 | ★★☆☆☆ Medium | ×1.3 | ×1.2 |
| 3 | ★★★☆☆ Hard | ×1.6 | ×1.5 |
| 4 | ★★★★☆ Expert | ×2.0 | ×1.8 |
| 5 | ★★★★★ Master | ×2.5 | ×2.2 |

### Настройки доступа трека

```
/ts trackedit option ALLOW_GARAGE_CARS   — разрешить использование машин из гаража
```

Если `ALLOW_GARAGE_CARS` выключено — все используют системную машину (fair play).

## Экономика

### Валюта (Rally Coins 🪙)

**Заработок:**
- Завершение трека: 20 монет (настраивается)
- Первое прохождение трека: ×3 бонус
- Побитие личного рекорда: +25 монет
- Попадание в топ-3 лидерборда: +100/+50/+25 монет
- Ежедневные задания: различные суммы

**Команды администратора:**

```
/coins admin give <игрок> <сумма>   — начислить монеты
/coins admin take <игрок> <сумма>   — списать монеты
/coins admin set <игрок> <сумма>    — установить баланс
```

**Команды игрока:**

```
/coins                  — показать баланс
/coins history          — история транзакций
/coins pay <игрок> <N>  — перевод другому игроку
```

## Система уровней

### Формула опыта

XP для достижения уровня N: `base × N × (1 + growth × (N - 1))`
- `base` = 100 (настраивается)
- `growth` = 0.15 (настраивается)
- Максимальный уровень: 100

Уровень отображается в XP-баре Minecraft.

**Команды администратора:**

```
/level admin setlevel <игрок> <уровень>   — установить уровень
/level admin addxp <игрок> <xp>           — начислить XP
```

**Команды игрока:**

```
/level           — текущий уровень, XP, прогресс
/level top       — топ по уровню
```

## Ежедневные задания

3 случайных задания генерируются каждый день для всех игроков (одинаковые для всех). Типы:
- `COMPLETE_TRACKS` — пройти N треков
- `BEAT_RECORD` — побить личный рекорд
- `COMPLETE_WITHOUT_RESET` — пройти без рестарта
- `COMPLETE_FIVE_TRACKS` — пройти 5 треков
- `FIRST_PLACE` — занять 1 место
- `COMPLETE_DIFFERENT_TRACKS` — пройти разные треки
- `COMPLETE_TEN_TRACKS` — пройти 10 треков
- `PARTICIPATE_TOURNAMENT` — участвовать в турнире
- `TOURNAMENT_TOP_THREE` — попасть в топ-3 турнира
- `COMPLETE_DIFFERENT_DIFFICULTY` — пройти треки разной сложности
- `WIN_STREAK` — серия побед

**Команды:**

```
/daily                    — текущие задания и прогресс (открывает GUI)
/daily admin regenerate   — пересоздать задания
```

## Гараж и кастомизация

### Компоненты машин

Каждая машина в гараже состоит из 7 компонентов с пресетами:

| Компонент | Кол-во пресетов | Что влияет |
|-----------|-----------------|------------|
| **Шины (TirePreset)** | 7 | Сцепление, скольжение, чувствительность |
| **Двигатель (EnginePreset)** | 5 | Мощность, торможение двигателем, сопротивление |
| **Кузов (BodyPreset)** | 5 | Масса, прижимная сила, аэродинамика |
| **Подвеска (SuspensionPreset)** | 4 | Жёсткость, высота ЦТ, стабильность |
| **Рулевое (SteeringPreset)** | 4 | Угол, скорость, отзывчивость |
| **Тормоза (BrakePreset)** | 4 | Тормозная сила, распределение |
| **Развесовка (WeightDistPreset)** | 4 | Распределение массы перед/зад |

Каждый пресет имеет **требуемый уровень** и **цену в монетах**.

### Управление гаражом

**Команды (или GUI):**

```
/garage                              — список машин (открывает GUI)
/garage create <имя>                 — создать новую машину
/garage select <id>                  — выбрать активную
/garage delete <id>                  — удалить
/garage info <id>                    — информация о машине
/garage upgrade <id> <компонент> <пресет>  — улучшить компонент
/shop [категория]                    — магазин пресетов (открывает GUI)
```

Максимум **5 машин** на игрока.

### Спавн машины из гаража

Хотбар-предмет (CHERRY_BOAT) показывает имя активной машины с её характеристиками. При спавне лодки применяются пресеты из гаража игрока (если трек разрешает кастомные машины).

## Система гонок

### Соло-рейсы

```
/race solo <трек> [system|custom]   — начать соло-рейс
/race cancel                        — отменить текущий рейс
/race leave                         — покинуть гонку
```

При соло-рейсе игрок **изолирован** — не видит других игроков и лодки.

### Мультиплеерные гонки

```
/race create <трек> [кругов] [питов]   — создать мультиплеерную гонку
/race join                              — присоединиться
/race start                             — запустить гонку
/race leave                             — покинуть
```

### Результаты

```
/race results <трек> [system|custom]   — результаты по треку
/race top <трек> [system|custom]       — топ-10 по треку
```

Результаты разделяются по типу машины (system / custom).

## Раллийные процедуры

### Стартовая процедура

Обратный отсчёт: 5... 4... 3... 2... 1... GO!
- Цветовая система: 🔴🔴🔴 → 🟡🟡🟡 → ✦ GO! ✦
- Звуки на каждую секунду
- Блокировка движения во время отсчёта

### Фальстарт

- Детекция: горизонтальное перемещение > 0.5 блоков во время отсчёта
- Штрафы:
  - 1-й фальстарт: +10 секунд штрафа
  - 2-й фальстарт: +60 секунд + рестарт
  - 3-й фальстарт: дисквалификация

```yaml
# В config.yml:
race:
  false_start:
    enabled: true
```

### Time Controls (контрольные точки)

- Тип региона: `TIMECONTROL`
- Допустимое время прибытия: target ± окно
- Штрафы:
  - Опоздание: +10 сек за каждую минуту
  - Раннее прибытие: +1 мин за каждую минуту
- Сводка при финише: raw time + penalties = total

### Сервис-парк

- Тип региона: `SERVICEPARK`
- Автоматический ремонт при нахождении в зоне
- Ограниченное время (настраиваемо)
- Восстанавливает: шины, двигатель, кузов

### Разведка трассы (Recce)

```
/race recce <трек>          — начать разведку (сниженная скорость)
/race recce end             — закончить
/race recce note <текст>    — оставить заметку на позиции
```

Режим проезда трассы на 50% скорости для изучения.

### Мультиэтапное ралли

```
/rally create <имя>                     — создать ралли
/rally addstage <ралли> <трек>          — добавить этап
/rally removestage <ралли> <трек>       — убрать этап
/rally start <ралли>                    — запустить
/rally join <ралли>                     — присоединиться
/rally retire <ралли>                   — сойти с дистанции
/rally results <ралли>                  — результаты
/rally info <ралли>                     — информация
/rally delete <ралли>                   — удалить
```

Суперралли: при сходе — +5 мин штрафа и возврат в следующий этап.

## Система поломок и износа

### Включение

```
/ts bume set damageEnabled true
```

### Износ шин

- Диапазон: 0.0 (новые) — 1.0 (изношены)
- При полном износе: -30% сцепления
- Факторы: скорость, поверхность (гравий ×2.5), стиль вождения

### Температура двигателя

- Нагрев при полном газе >30 сек
- Перегрев: до -50% мощности
- Охлаждение при сбросе газа

### Повреждения кузова

| Уровень | Диапазон | Эффекты |
|---------|----------|---------|
| Нет | 0.0–0.3 | Без эффектов |
| Минорный | 0.3–0.6 | -10% руль |
| Умеренный | 0.6–0.8 | -10% руль, -20% мощность |
| Критический | 0.8–1.0 | -15% руль, -20% мощность, -50% макс. скорость |

### Визуальные эффекты

- Дым при bodyDamage > 0.5
- Искры при столкновениях
- Индикатор температуры в HUD (цвет: синий→зелёный→жёлтый→красный)

## Античит

### Что проверяется

- **Скорость:** максимально допустимая для типа машины (+20% допуск)
- **Ускорение:** аномальные изменения скорости
- **Телепортация:** перемещение на большие расстояния
- **Конфигурация машины:** пресеты существуют и разблокированы
- **Экономика:** rate limiting, лимит переводов, детекция дюпов

### Действия при нарушении

1. Предупреждение (1-й раз)
2. Телепорт на последнюю безопасную позицию (2-й раз)
3. Дисквалификация + кулдаун 30 сек (3-й раз)
4. Уведомление админам

### Конфигурация

```yaml
anticheat:
  enabled: true
  check_interval_ticks: 10
  speed_tolerance: 1.2
  max_violations: 3
  notify_admins: true
  log_violations: true
```

## Телеметрия

Система записи и валидации данных каждого рейса.

### Клиент (мод)

- Запись каждый тик: позиция, скорость, руление, газ, тормоз, углы скольжения, G-force
- Формат: `.ibrt` (бинарный, GZIP-сжатый)
- Локальное сохранение: `.minecraft/ibrealistic/telemetry/`
- Автоматическая отправка на сервер при финише

### Сервер (плагин)

- Приём и сборка из фрагментов (чанки по 16 КБ)
- Валидация: целостность, позиция, скорость, ускорение, непрерывность
- Хранение: `plugins/TimingSystem/telemetry/{uuid}/`
- Без валидной телеметрии рейс считается **невалидным**

### Статусы валидации

| Статус | Значение |
|--------|----------|
| `VALID` | Рейс подтверждён — засчитывается |
| `INVALID` | Рейс не прошёл проверку — только 20% наград |
| `SUSPICIOUS` | На проверке — уведомление админам |
| `PENDING` | Ожидание телеметрии |

## Ghost Racing

Система «призраков» — игрок видит запись лучшего заезда в реальном времени.

### Команды

```
/line                                — переключить ghost ON/OFF
/line mode OFF|LINE|BOAT|COMPETITION — выбрать режим отображения
/line count <N>                      — макс. количество призраков (COMPETITION)
/line info                           — текущие настройки
```

### Режимы отображения

| Режим | Описание |
|-------|----------|
| `OFF` | Призраки выключены |
| `LINE` | Линия-трейл по траектории |
| `BOAT` | Полупрозрачная лодка |
| `COMPETITION` | Несколько призраков из лидерборда |

### Автоматическое сохранение

При финише с валидной телеметрией, если время лучше личного рекорда — ghost автоматически сохраняется для данного игрока и трека.

## Турниры

### Автоматические еженедельные турниры

По умолчанию турнир стартует каждый понедельник в 00:00 UTC и длится 7 дней.

### Типы турниров

| Тип | Описание |
|-----|----------|
| `SPRINT` | Лучшее время на одном треке |
| `RALLY` | Суммарное время по серии треков (3–5) |
| `ENDURANCE` | Максимум кругов за фиксированное время |
| `BRACKET` | Двойная элиминация (макс. 64 игрока) |

### Рейтинговая система (Glicko-2)

- Начальный рейтинг: 1000
- Обновляется после каждого турнира
- Ранги:
  - 🥉 Bronze: 0–999
  - 🥈 Silver: 1000–1299
  - 🥇 Gold: 1300–1599
  - 💎 Diamond: 1600–1899
  - 👑 Champion: 1900+

### Сезоны

- Длительность: 3 месяца (настраивается)
- Очки за позицию в турнире (F1-стиль): 25, 18, 15, 12, 10, 8, 6, 4, 2, 1
- Soft reset рейтинга при новом сезоне

### Команды

**Игрокам:**

```
/tournament                   — текущий активный турнир
/tournament results           — результаты
/tournament top               — топ участников
/tournament history           — история турниров
/tournament rating            — рейтинг ELO
/tournament season            — текущий сезон
```

**Администраторам:**

```
/tournament admin create <тип> [треки...]   — ручное создание
/tournament admin cancel                    — отмена текущего
/tournament admin rewards <позиция> <монеты> <xp>  — настройка наград
/tournament admin season start              — начать новый сезон
```

## Устранение проблем

### Мод не подключается к серверу

- Убедитесь, что OpenBoatUtils и IBRealistic установлены на клиенте
- Проверьте версии: `VERSION` протокола должен совпадать
- В логах сервера появляется `REALISTIC_CLIENT_INFO` при подключении

### Физика не работает

- Убедитесь, что режим трека включает `realisticPhysics: true`
- Проверьте Feature Flags в `config.yml` (`fourWheel: true`)
- Игрок должен иметь мод IBRealistic

### Рейсы не засчитываются

- Телеметрия должна быть включена (`telemetry.enabled: true`)
- Рейс без телеметрии = невалидный
- Проверьте `telemetry.required_for_valid_race`
- Убедитесь, что нет ошибок при передаче данных (логи плагина)

### Ghost не отображается

- Ghost сохраняется только при финише с VALID телеметрией
- Игрок должен включить ghost: `/line mode BOAT` или `/line mode LINE`
- Проверьте `ghost.enabled: true` в config.yml

### Турниры не запускаются

- Проверьте `tournaments.enabled: true`
- Автозапуск: `auto_start_day` и `auto_start_hour`
- Минимум `min_players` участников для завершения турнира
- Убедитесь, что есть доступные треки
