# Изменения: Исправление остановки и улучшение массообмена

## Дата
2026-02-08

## Краткое описание
Исправлена проблема со странным движением после полной остановки (осцилляция). Улучшен поперечный массообмен — теперь корректно уменьшает эффективное сцепление вместо общей нагрузки на ось.

## Изменённые файлы

### Мод (OpenBoatUtilsRealistic)
- `physics/RealisticPhysicsEngine.java` — добавлена мёртвая зона (dead zone), плавное затухание сил, исправлен поперечный массообмен, добавлена защита от реверса при торможении
- `physics/TireModel.java` — увеличен MIN_SPEED (0.5→1.0) для исключения боковых сил при стоянке, исправлена тормозная сила при vx ≈ 0

## Детальное описание изменений

### 1. Dead Zone при остановке (RealisticPhysicsEngine.java)
**Что сделано:**
- Добавлена `STOP_SPEED_THRESHOLD = 0.15 м/с` — ниже этой скорости (без газа) все скорости обнуляются
- Добавлена `LOW_SPEED_FADE_THRESHOLD = 0.5 м/с` — плавное затухание сил при приближении к нулю
- Rolling resistance использует `vx / max(|vx|, 0.5)` вместо `signum(vx)` — плавный переход вместо скачка ±1
- Engine braking аналогично использует плавное затухание
- Добавлена защита от реверса — тормозные силы не могут развернуть направление движения

**Причина:**
`Math.signum(vx)` даёт -1 или +1, что при vx ≈ 0 создаёт осцилляцию: сила толкает машину назад → signum меняется → толкает вперёд → и т.д. бесконечно.

### 2. Исправленный поперечный массообмен
**Что сделано:**
- Поперечный массообмен больше НЕ уменьшает общую нагрузку на ось (fzFront/fzRear)
- Вместо этого он уменьшает эффективный коэффициент трения (muFront/muRear)
- Это моделирует нелинейность шин: средний grip двух неравномерно нагруженных колёс < grip при средней нагрузке
- Потеря grip ограничена 50% для предотвращения нестабильности

**Причина:**
Старый подход вычитал поперечный массообмен из ОБЩЕЙ нагрузки на ось, что физически некорректно. В реальности поперечный массообмен перераспределяет нагрузку между внутренним и внешним колёсами одной оси, не меняя суммарную нагрузку.

### 3. Улучшенная модель шин (TireModel.java)
**Что сделано:**
- `MIN_SPEED` увеличен с 0.5 до 1.0 м/с — при очень низких скоростях модель шин не генерирует ложные боковые силы
- Тормозная сила использует `vx / max(|vx|, 0.5)` вместо `signum(vx)` — предотвращает осцилляцию
