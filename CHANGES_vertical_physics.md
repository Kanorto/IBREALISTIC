## Детальное описание изменений

### 1. Вертикальная физика (RealisticPhysicsEngine.java)

**Новые константы:**
- `LANDING_IMPACT_THRESHOLD = -1.5f` — порог вертикальной скорости для определения "жёсткой посадки"
- `MAX_LANDING_GRIP_LOSS = 0.6f` — максимальная потеря сцепления при приземлении (60%)
- `LANDING_GRIP_RECOVERY_RATE = 0.08f` — скорость восстановления сцепления (за тик)
- `VERTICAL_PITCH_FACTOR = 0.15f` — коэффициент наклона лодки от вертикальной скорости
- `MAX_VERTICAL_PITCH = 0.5f` — максимальный вертикальный наклон
- `MIN_AIRBORNE_TICKS_FOR_IMPACT = 3` — минимальное время в воздухе для учёта удара

**Новые поля состояния:**
- `wasAirborne` — предыдущее состояние полёта (для детекции посадки)
- `airborneTicks` — счётчик тиков в воздухе
- `landingGripPenalty` — текущее снижение сцепления от удара (0-0.6)
- `verticalVelocity` — вертикальная скорость в м/с

**Логика работы:**
1. Каждый тик отслеживается вертикальная скорость из entityVel.y
2. При переходе из воздуха на землю рассчитывается сила удара
3. Сила удара зависит от: вертикальной скорости при посадке и времени в воздухе
4. Небольшие кочки (малое время в воздухе, малая скорость) — минимальная потеря сцепления
5. Большие прыжки с жёстким приземлением — значительная временная потеря сцепления
6. Сцепление плавно восстанавливается со скоростью 0.08 за тик (~0.75 секунды для полного восстановления)
7. В воздухе лодка наклоняется: нос вверх при подъёме, нос вниз при падении

### 2. Расширенный маппинг блоков (SurfaceProperties.java)

**9 новых типов поверхностей:**
| Тип | muPeak | muSlide | Cornering Stiffness | Rolling Resistance |
|-----|--------|---------|---------------------|--------------------|
| WOOD | 0.50 | 0.42 | 35000 | 0.020 |
| CONCRETE | 0.80 | 0.65 | 60000 | 0.013 |
| TERRACOTTA | 0.65 | 0.55 | 45000 | 0.018 |
| METAL | 0.70 | 0.55 | 55000 | 0.010 |
| GLASS | 0.35 | 0.25 | 40000 | 0.008 |
| WOOL | 0.70 | 0.60 | 28000 | 0.045 |
| BRICK | 0.75 | 0.60 | 55000 | 0.016 |
| NETHER | 0.50 | 0.40 | 35000 | 0.025 |
| VEGETATION | 0.40 | 0.35 | 22000 | 0.040 |

**Баланс:**
- CONCRETE — лучшая "дорога" для быстрой езды (близко к ASPHALT_DRY, но чуть хуже)
- BRICK — хорошая поверхность, подходит для городских трасс
- METAL — быстро, но с умеренным сцеплением
- WOOD — средний вариант, хорошо для лесных трасс
- TERRACOTTA — чуть хуже бетона, но стабильная
- WOOL — высокое сцепление, но сильно замедляет (мягкая поверхность)
- GLASS — скользкая, опасная
- NETHER — среднее сцепление, для адских трасс
- VEGETATION — мягко и медленно, для природных трасс

### 3. Режим REALISTIC_ALLTERRAIN

Новый режим для езды по всем типам блоков:
- Базовая скользкость 0.98 (все блоки)
- Нет урона от падения
- Управление в воздухе включено
- Высота ступеньки 1.25 блока
- Шагание при падении включено (canStepWhileFalling)
- Тип машины: WRC_CAR
