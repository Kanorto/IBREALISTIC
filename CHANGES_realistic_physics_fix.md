# Изменения: Исправление реалистичной физики

## Дата
2026-02-08

## Краткое описание
Исправлена остановка лодки в воздухе при переходе между блоками в реалистичных режимах. Добавлены обязательные настройки (airControl, slipperiness) для всех REALISTIC пресетов. Обновлена документация SERVER_GUIDE.md.

## Изменённые файлы

### Мод (OpenBoatUtilsRealistic)
- `src/main/java/dev/o7moon/openboatutils/mixin/BoatMixin.java` — реалистичная физика теперь работает в состоянии IN_AIR (при включённом airControl)
- `src/main/java/dev/o7moon/openboatutils/Modes.java` — все REALISTIC режимы теперь устанавливают `setAllBlocksSlipperiness(0.98f)`

### Документация
- `codebase/SERVER_GUIDE.md` — добавлено предупреждение о обязательных параметрах для кастомных реалистичных режимов, обновлены примеры

## Детальное описание изменений

### 1. Исправление остановки в воздухе (BoatMixin.java)
**Файл:** `src/main/java/dev/o7moon/openboatutils/mixin/BoatMixin.java`
**Строки:** 128-139
**Что сделано:**
- Реалистичная физика теперь работает не только при `loc == ON_LAND`, но и при `loc == IN_AIR` (если `airControl == true`)
- Это предотвращает потерю скорости при переходе лодки с одного блока на нижний

**Причина:**
Ранее реалистичная физика применялась ТОЛЬКО на земле. Когда лодка съезжала с блока на нижний, она на мгновение оказывалась в состоянии `IN_AIR`, и физический движок переставал работать. Лодка теряла управление и скорость. В режиме RALLY это было решено через `airControl`, но реалистичные режимы не использовали эту механику.

### 2. Добавление slipperiness для REALISTIC режимов (Modes.java)
**Файл:** `src/main/java/dev/o7moon/openboatutils/Modes.java`
**Строки:** 192-234
**Что сделано:**
- Все REALISTIC режимы (REALISTIC, REALISTIC_WRC, REALISTIC_GROUP_B, REALISTIC_CLASSIC, REALISTIC_LIGHTWEIGHT, REALISTIC_TRUCK) теперь устанавливают `setAllBlocksSlipperiness(0.98f)` как в режиме RALLY
- Режим REALISTIC ранее использовал 0.9f, остальные не устанавливали вовсе

**Причина:**
Без установки slipperiness для всех блоков, ванильная физика Minecraft обрабатывала трение блоков, что приводило к непредсказуемому поведению на разных поверхностях. Значение 0.98f (как в RALLY) обеспечивает плавное скольжение, необходимое для корректной работы реалистичной физики.

### 3. Обновление SERVER_GUIDE.md
**Файл:** `codebase/SERVER_GUIDE.md`
**Что сделано:**
- Добавлено предупреждение в раздел настроек реалистичной физики о обязательных параметрах
- Обновлены все примеры создания кастомных режимов — добавлены `boatAirControl true`, `defaultSlipperiness 0.98`, `stepHeight 1.25`

## Проблемы и решения
- **Проблема:** Лодка останавливалась при переходе между блоками разной высоты
- **Решение:** Разрешить реалистичной физике работать в IN_AIR (при airControl), добавить slipperiness 0.98f
- **Проблема:** Кастомные режимы bumode не работали корректно
- **Решение:** Обновлена документация — пользователь должен устанавливать boatAirControl, defaultSlipperiness и stepHeight для кастомных режимов
