## Детальное описание изменений

### 1. Исправление потери скорости в поворотах
**Файл:** `FourWheelPhysicsEngine.java`

**Проблема:** Машина слишком быстро теряла скорость при повороте из-за агрессивного гашения боковой скорости.

**Что сделано:**
- `LATERAL_VELOCITY_DAMPING`: 0.97 → 0.985 (меньше потерь при повороте без руля)
- `LATERAL_VELOCITY_DAMPING_ACTIVE`: 0.99 → 0.995 (меньше потерь при активном рулении)
- `STRAIGHT_LINE_LATERAL_DAMPING`: 0.90 → 0.93 (менее агрессивное гашение при прямолинейном движении)
- `MAX_LATERAL_SPEED_RATIO`: 1.2 → 1.5 (больший допуск бокового скольжения)

### 2. Исправление неработающего ручника
**Файл:** `FourWheelPhysicsEngine.java`

**Проблема:** Ручник только добавлял тормозное усилие на задние колёса, но не снижал их сцепление. Результат — задние колёса замедлялись, но не теряли боковое сцепление, поэтому не было заноса.

**Что сделано:**
- Добавлена константа `HANDBRAKE_REAR_GRIP_MULTIPLIER = 0.25f` — при ручнике сцепление задних колёс снижается на 75%
- `HANDBRAKE_FORCE_MULTIPLIER`: 0.8 → 1.2 (более сильное тормозное усилие)
- Добавлен блок кода, который при нажатом ручнике умножает `muWheel` задних колёс на 0.25, что вызывает потерю бокового сцепления и занос задней оси (овершир)

**Принцип работы:**
1. Ручник блокирует задние колёса → фрикционный круг уменьшается (mu × 0.25)
2. Боковые силы задних шин ограничиваются уменьшенным фрикционным кругом
3. Задняя ось скользит боком → машина уходит в занос
4. Передние колёса сохраняют полное сцепление → можно управлять заносом

### 3. Уменьшение скорости разворота
**Файл:** `FourWheelPhysicsEngine.java`

**Проблема:** Машина слишком быстро разворачивалась, что выглядело нереалистично.

**Что сделано:**
- `YAW_RATE_DAMPING`: 0.995 → 0.985 (более сильное гашение угловой скорости)
- `MAX_YAW_RATE`: 15.0 → 8.0 рад/с (ограничение максимальной скорости вращения)
- Момент инерции увеличен в 1.8 раза (`inertia = 1.8f * m * (L² + W²) / 12`) — реалистичное распределение масс с учётом двигателя, КПП, топливного бака

**Обоснование:**
- Формула `m*(L²+W²)/12` — это момент инерции для равномерно распределённой массы
- Реальный автомобиль имеет концентрированные массы (двигатель, трансмиссия), увеличивающие момент инерции
- Коэффициент 1.8 соответствует типичному радиусу инерции реального автомобиля
