# Изменения: Исправление колёс и визуальный руль

## Дата
2026-02-12

## Краткое описание
Исправлены направления вращения и поворота колёс, исправлена ось позиционирования колёс (передние/задние), увеличен WHEEL_RADIUS до 2.0, добавлен визуальный руль с наклоном 45° и отображением реального угла поворота.

### Мод (OpenBoatUtilsRealistic)
- `src/main/java/dev/o7moon/openboatutils/client/WheelRenderer.java` — исправлены оси позиционирования и направления вращения

## Детальное описание изменений

### 1. Исправление осей позиционирования колёс
**Файл:** `WheelRenderer.java`
**Что сделано:**
- Исправлен комментарий координатной системы: X = продольная ось (вперёд/назад), Z = поперечная ось (влево/вправо)
- Переименованы константы: `FRONT_Z_OFFSET` → `FRONT_X_OFFSET`, `REAR_Z_OFFSET` → `REAR_X_OFFSET`
- Передние колёса теперь позиционируются по X (продольная ось), боковое смещение по Z (поперечная ось)
- Ранее оси были перепутаны: передние колёса ставились на одну сторону, а не спереди

**Причина:**
После трансформаций `scale(-1,-1,1)` и `rotateY(90)` в ванильном рендерере, X и Z оси меняются местами относительно модели лодки. Предыдущий код неправильно комментировал систему координат и размещал колёса по неверным осям.

### 2. Исправление направления вращения и поворота колёс
**Файл:** `WheelRenderer.java`
**Что сделано:**
- Добавлена инверсия углов вращения (spin) и поворота (steering) для компенсации `scale(-1,-1,1)`
- `visualSteeringDeg = -steeringDegrees` — правильное направление поворота колёс
- `visualFrontSpin = -interpolatedSpin` — правильное направление вращения колёс
- `visualRearSpin = -rearSpin` — правильное направление для задних колёс

**Причина:**
Трансформация `scale(-1,-1,1)` инвертирует X и Y оси, что приводит к визуально обратному направлению вращений вокруг этих осей.

### 3. Увеличение WHEEL_RADIUS
**Файл:** `WheelRenderer.java`
**Что сделано:**
- `WHEEL_RADIUS` изменён с `1.6f` на `2.0f`

**Причина:**
По запросу пользователя — колёса были слишком маленькие.

### 4. Добавление визуального руля
**Файл:** `SteeringWheelRenderer.java` (новый файл)
**Что сделано:**
- Создан рендерер руля с узнаваемой круглой формой
- Обод (rim): 8 сегментов-кубоидов, образующих кольцо
- Спицы (spokes): 3 штуки под углами 0°, 120°, 240°
- Ступица (hub): центральная часть
- Наклон рулевой колонки: 45° к игроку
- Визуальный коэффициент поворота: 2.5x (руль крутится в 2.5 раза быстрее реального угла колёс)
- Текстуры: тёмный дуб для обода, серый бетон для ступицы
- Руль отображается только при активной реалистичной физике

### 5. Интеграция в рендерер лодки
**Файл:** `BoatEntityRendererMixin.java`
**Что сделано:**
- Добавлен импорт `SteeringWheelRenderer`
- Добавлен вызов `SteeringWheelRenderer.renderSteeringWheel()` в обеих ветках (MC ≤1.21 и ≥1.21.3)
- Руль рендерится после колёс, но до закрытия матрицы
