# Изменения: Фаза 6 — Баги и стабильность физики

## Дата
2026-02-12

## Краткое описание
Исправлена проблема бокового дрейфа (BUG-1) при приземлении и прямолинейном движении. Добавлена debug-команда для диагностики физики.

## Изменённые файлы

### Мод (OBURealistic)
- `physics/FourWheelPhysicsEngine.java` — полный сброс бокового состояния при приземлении, улучшенное демпфирование vy, пересчёт expectedWorld после приземления
- `mixin/BoatMixin.java` — debug HUD в action bar, вспомогательная функция getSurfaceName, сохранение скорости при приземлении (moveHook)
- `OpenBoatUtils.java` — добавлено поле realisticDebugHud
- `SingleplayerCommands.java` — добавлена команда /realisticdebug

## Детальное описание изменений

### 1. Полный сброс бокового состояния при приземлении
**Файл:** `physics/FourWheelPhysicsEngine.java`
**Что сделано:**
- Добавлена константа `LANDING_FULL_RESET_AIRBORNE_TICKS = 5` — порог для полного сброса
- При приземлении после полёта ≥5 тиков: `vy = 0`, `fyActual[] = 0`, `yawRate *= 0.5`
- При коротком прыжке (<5 тиков): прежнее поведение (×0.5 демпфирование)
- После сброса — пересчёт `expectedWorldVx/Vz` для предотвращения ложных коллизий

**Причина:**
BUG-1: vy и fyActual[] накапливали воздушные значения при каждом приземлении. Множитель 0.5 не обнулял их полностью, что приводило к прогрессирующему боковому дрейфу при повторных прыжках.

### 2. Улучшенное прямолинейное демпфирование vy
**Файл:** `physics/FourWheelPhysicsEngine.java`
**Что сделано:**
- Добавлены константы: `STRAIGHT_LINE_LATERAL_DAMPING = 0.90`, `STRAIGHT_LINE_YAW_RATE_THRESHOLD = 0.3`
- Когда руль не повёрнут И yawRate < 0.3 рад/с: применяется демпфирование vy *= 0.90 (вместо 0.97)
- При повороте (активный руль или высокий yawRate): прежнее поведение

**Причина:**
При прямолинейном движении остаточный vy должен быстро затухать. Ранее он мог накапливаться из-за слабого демпфирования (0.97), что создавало видимый боковой дрейф.

### 3. Пересчёт expectedWorldVx/Vz после приземления
**Файл:** `physics/FourWheelPhysicsEngine.java`
**Что сделано:**
- После сброса vy при приземлении, expectedWorldVx/Vz пересчитываются из обновлённого vx/vy
- Это предотвращает ситуацию, когда на следующем тике коллизия обнаруживается из-за несоответствия ожидаемой и реальной скорости, что заново инжектирует ложный vy

### 4. Debug HUD команда
**Файлы:** `OpenBoatUtils.java`, `SingleplayerCommands.java`, `BoatMixin.java`
**Что сделано:**
- Добавлено поле `realisticDebugHud` (volatile boolean) в OpenBoatUtils
- Команда `/realisticdebug` переключает HUD
- В BoatMixin: отображение в action bar: `vx=X.XX vy=X.XX yr=X.XXX AIR/GND surf=NAME`
- Вспомогательный метод `getSurfaceName()` для отображения имени поверхности

### 5. Сохранение скорости при приземлении (BUG-2)
**Файл:** `mixin/BoatMixin.java` (moveHook)
**Что сделано:**
- Добавлены константы: `LANDING_SPEED_LOSS_THRESHOLD = 0.3`, `LANDING_SPEED_RESTORE_FACTOR = 0.85`
- В `moveHook()`: сохранение горизонтальной скорости перед `move()`
- После `move()`: если лодка приземлилась (Y velocity стала больше) и потеряла >30% горизонтальной скорости, восстанавливается 85% в направлении движения
- Различение стены vs. земли: если forward component < 10% от исходной скорости — это стена, скорость не восстанавливается

**Причина:**
BUG-2: Vanilla `move()` клиппит горизонтальную скорость при столкновении с землёй, что приводит к резкой остановке при приземлении с прыжка.

## Аудит граничных условий (6.3)
Проверены следующие случаи:
- ✅ Скорость 0 → isStationary обнуляет всё, NaN/Infinity защита есть
- ✅ Скорость > 80 м/с → MAX_VELOCITY = 100 clamp
- ✅ yawRate > 10 рад/с → MAX_YAW_RATE = 15 clamp
- ✅ Переход поверхностей → per-tick детекция через detectSurface()
- ✅ Коллизия со стеной → collision detection + MAX_COLLISION_LATERAL_INJECTION
- ✅ Езда задом (S) → vxAbs = max(|vx|, 1.0) предотвращает деление на 0
- ✅ Газ + тормоз → friction circle ограничивает обе силы
- ✅ NaN/Infinity → защита в каждом substep с полным сбросом
