# Журнал изменений (Changelog)

Все заметные изменения в проекте IBRealistic документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено
- Реалистичные скорости руления на основе данных WRC:
  - WRC_CAR: 1.4 рад/с (было 5.0)
  - GROUP_B: 1.2 рад/с (было 4.5)
  - CLASSIC_RALLY: 1.0 рад/с (было 4.0)
  - LIGHTWEIGHT: 1.6 рад/с (было 6.0)
  - TRUCK: 0.8 рад/с (было 3.0)
- Скорость возврата руля: 1.5 рад/с (было 3.0)
- Рендерер рулевого колеса: наклон 45°, отображение реального угла поворота
- Приподнятая позиция пассажира
- **Инициализация скорости с учётом столкновений**: предотвращает ложные боковые силы при ударе о стены
- **Сохранение инерции при приземлении**: плавный переход воздух→земля, предотвращает резкие остановки
- Рендеринг колёс: увеличенный радиус (2.5), расширенное расстояние между колёсами
- Реалистичная блокировка задних колёс при ручном тормозе
- Визуальный радиус рулевого колеса увеличен до 2.5, перемещён к носу лодки

### Исправлено
- Исправлена ориентация визуальных колёс

### Изменено
- Обновлены параметры рендеринга колёс и рулевого колеса

## [2026-02-11]

### Добавлено
- Семантическое версионирование: формат `{obu_version}-{realistic_version}_{mc_version}`
- Автоматические релизы через git-теги (CI/CD): `build-release.yml`, `prerelease.yml`
- Система спавна: предметы хотбара (/tt, /reset, /b), кулдаун 2 секунды
- Тюнинг системы тяги: демпфирование боковой силы в воздухе, восстановление сцепления, дифференциалы для каждого типа машины
- Визуальные улучшения колёс: размер увеличен на 60%, октагональный профиль, диск ступицы
- Нормализация цветовых кодов Triton (исправлено 369 переводов)

### Исправлено
- Исправлено двойное применение ванильной физики
- FPS-независимое вращение колёс
- Исправлено инвертированное управление рулём
- Критическое исправление: velocityDecay ordinal (использовался неверный индекс перечисления)
- Исправлена потеря гравитации из-за отменённого updateVelocity
- Возврат BoatMixin к версии v1.0.1 (удалено подавление ванильной физики)

### Изменено
- Обновлена проверка версии для статуса реалистичного мода

## [2026-02-09]

### Добавлено
- Полноценный 4-колёсный физический движок (замена bicycle model)
- Типы дифференциалов (Open, Locked, LSD) для каждой оси
- Система погодных условий (влияет на сцепление)
- Аэродинамическая прижимная сила (downforce)
- Обнаружение реалистичного мода (пинг игрокам без мода)

### Исправлено
- Исправления потокобезопасности (thread-safety)
- Оптимизация сборщика мусора (SurfaceAccumulator)

### Изменено
- SurfaceProperties сделан неизменяемым (immutable)
- Версия протокола: 18 → 20

## [2026-02-08]

### Добавлено
- Вертикальная физика: кочки, прыжки, приземления
- Маппинг поверхностей расширен до 300+ блоков
- Режим REALISTIC_ALLTERRAIN — вездеход для всех типов блоков
- Аэродинамика в воздухе: сопротивление, демпфирование рыскания
- Самовыравнивающий момент руля (self-aligning torque)
- Реакция рулевого управления (плавный отклик)

### Исправлено
- Унификация BoatMixin/AbstractBoatMixin с предикатами Stonecutter (исправление сборки)
- Исправлена потеря скорости в воздухе
- Исправлен нефункциональный ручной тормоз
- Устранение осцилляции при остановке (мёртвые зоны)
- Коррекция поперечного переноса массы (lateral load transfer)
