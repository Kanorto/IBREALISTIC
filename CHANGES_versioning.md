## Детальное описание изменений

### 1. Схема версионирования
**Формат мода:** `{obu_version}-{realistic_version}_{mc_version}`
- Пример: `0.4.10-1.0.5_1.20.4`

**Формат плагина:** `{ts_base_version}-{realistic_version}`
- Пример: `3.2-1.0.5`

### 2. Протокол VERSION
- Возвращён к 18 (базовый OBU) в соответствии с гайдлайнами контрибуции оригинального проекта

### 3. CI/CD автоматизация

**Пререлизы** (`prerelease.yml`):
- Триггер: merge PR в main
- Автоматически определяет следующий номер пререлиза (четвёртый сегмент)
- Создаёт тег `vX.X.X.N` и GitHub Pre-release с артефактами
- Номер сбрасывается при создании полного релиза

**Полные релизы** (`build-release.yml`):
- Триггер: push тега формата `vX.X.X` (трёхсегментный)
- Собирает мод для всех MC версий и плагин
- Создаёт GitHub Release с auto-generated release notes
- Прикрепляет JAR артефакты к релизу
