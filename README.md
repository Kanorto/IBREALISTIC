# IBREALISTIC

Мод (Fabric) и плагин (Paper) для Minecraft, превращающий лодки в раллийные автомобили с реалистичной физикой. Основан на OpenBoatUtils и TimingSystem.

## Возможности

- **Четырёхколёсная физическая модель** — каждое колесо рассчитывает сцепление, нагрузку и силу отдельно
- **Модель шин Fiala/Brush** — реалистичное поведение при скольжении, заносе и дрифте
- **Перенос массы** — продольный (торможение/разгон) и поперечный (повороты)
- **Дифференциалы** — Open, Locked, LSD для каждой оси
- **5 типов машин** — WRC, Group B, Classic Rally, Lightweight, Truck
- **300+ маппированных блоков** — каждый тип покрытия имеет свои характеристики сцепления
- **Аэродинамика** — прижимная сила (downforce) и сопротивление воздуха
- **Погодные условия** — влияют на сцепление
- **Визуальные элементы** — 4 колеса, рулевое колесо, крен, клевок
- **Мультиверсионность** — MC 1.20.4, 1.21, 1.21.3

## Структура

- `OpenBoatUtilsRealistic/` — мод для клиента (Fabric, Java 21)
- `TimingSystem/` — серверный плагин (Paper, Maven)
