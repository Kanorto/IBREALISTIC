# IBRealistic

Аддон-мод (Fabric) и серверный плагин (Paper) для Minecraft, превращающий лодки в раллийные автомобили с реалистичной физикой. Работает поверх OpenBoatUtils и TimingSystem.

## Возможности

- **Четырёхколёсная физическая модель** — каждое колесо рассчитывает сцепление, нагрузку и силу отдельно
- **Модель шин Fiala/Brush** — реалистичное поведение при скольжении, заносе и дрифте
- **Перенос массы** — продольный (торможение/разгон) и поперечный (повороты)
- **Дифференциалы** — Open, Locked, LSD для каждой оси
- **5 типов машин** — WRC, Group B, Classic Rally, Lightweight, Truck
- **300+ маппированных блоков** — каждый тип покрытия имеет свои характеристики сцепления
- **Аэродинамика** — прижимная сила (downforce) и сопротивление воздуха
- **Погодные условия** — влияют на сцепление (CLEAR, RAIN, HEAVY_RAIN, SNOW, FOG)
- **Визуальные элементы** — 4 колеса, рулевое колесо, крен, клевок, частицы, звуки
- **Экономика** — Rally Coins, уровни, ежедневные задания
- **Кастомизация** — гараж с 5 машинами, 7 типов компонентов, магазин пресетов
- **Система гонок** — соло с изоляцией, мультиплеер, лидерборды
- **Раллийные процедуры** — фальстарт, контрольные точки, сервис-парк, разведка, мультиэтапы
- **Поломки и износ** — износ шин, перегрев двигателя, повреждения кузова
- **Античит** — серверная валидация скорости, защита экономики
- **Телеметрия** — запись и валидация каждого рейса
- **Ghost Racing** — соревнуйтесь с призраком лучшего времени
- **Турниры** — автоматические еженедельные с рейтингом Glicko-2 и сезонами
- **GUI** — магазин, гараж, профиль, задания, настройки
- **Мультиверсионность** — MC 1.20.4, 1.21, 1.21.3
- **Мультиязычность** — 9 языков + Triton интеграция

## Структура

- `IBRealistic/` — аддон-мод для клиента (Fabric, Java 21)
- `TimingSystem/` — серверный плагин (Paper, Maven)
