# OBURealistic
OBURealistic is a client mod that gives server plugins an interface to modify boat physics with realistic rally car dynamics. Based on OpenBoatUtils, it adds four-wheel physics, tire grip model, weight transfer, differentials, surface-specific friction, weather conditions, and visual wheels.
