### 2. Добавление раздела о Кодовой базе
**Файл:** `.github/copilot-instructions.md`
**Строки:** 211-280 (новый раздел)
**Что сделано:**
Добавлен критически важный раздел "Кодовая база (CODEBASE_INDEX.md)" с требованиями:

- **Назначение кодовой базы:**
  - Полный индекс всех файлов проекта с описанием
  - Индекс всех публичных классов и методов
  - Связи между компонентами
  - Точки расширения для новых фич

- **Обязательное требование:**
  - При ЛЮБОМ изменении кода агент ДОЛЖЕН обновить CODEBASE_INDEX.md
  - Добавлять новые файлы в индекс с описанием
  - Добавлять новые функции/методы в индекс класса
  - Обновлять описание при изменении назначения
  - Отражать новые связи между компонентами

- **Структура CODEBASE_INDEX.md:**
  - Содержание с разделами: Мод, Плагин, Связи, Точки расширения
  - Детальное описание каждого файла с методами
  - Диаграммы потоков данных
  - Инструкции по расширению

- **Важные примечания:**
  - Кодовая база будет создана позже
  - Пока её нет — УПОМИНАТЬ в CHANGES_*.md необходимость обновления
  - НЕ создавать CODEBASE_INDEX.md самостоятельно
  - Когда файл появится — ОБЯЗАТЕЛЬНО обновлять при каждом изменении

**Причина:**
По требованию пользователя необходимо обеспечить поддержку кодовой базы — индекса файлов и функций, который будет создан в будущем и должен обновляться при каждом изменении кода.
