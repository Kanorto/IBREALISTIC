# План реалистичного ралли — IBRealistic

> **Архитектура:** IBRealistic — аддон к OpenBoatUtils (OBU). OBU используется как неизменяемая зависимость (пакеты 0–32 на `openboatutils:settings`). IBRealistic — основной проект, обрабатывает пакеты 33–69 на `ibrealistic:settings`. Пакет: `dev.kanorto.ibrealistic`. VERSION протокола: **21**.
>
> **⚠️ OBU (OpenBoatUtils-main/) — НЕИЗМЕНЯЕМ.** Это внешняя зависимость, код OBU нельзя модифицировать. Все изменения делаются ТОЛЬКО в IBRealistic/ и TimingSystem/.
>
> **Структура документа:** Завершённые фазы (1–5b) → Известные баги → Текущие/будущие фазы (6–17) с порядком зависимостей.
> Каждый шаг включает работу с переводами (lang/*.yml + triton.yml + triton/timingsystem.json).
> Функционал всегда реализуется **до** визуала: нельзя делать GUI без готового бэкенда.

# ИЗВЕСТНЫЕ БАГИ И ПРОБЛЕМЫ 🐛

## BUG-1: Накопление воздушного состояния ✅ ИСПРАВЛЕНО
**Приоритет:** ВЫСОКИЙ — влияет на геймплей
**Статус:** Исправлено в Фазе 6.1
**Симптомы:**
- Первый прыжок проходит нормально (кроме резкой остановки при приземлении)
- Второй и последующие прыжки тянут машину в сторону
- Эффект накапливается: каждый следующий прыжок хуже предыдущего

**Причина:** `vy` и `fyActual[]` не обнулялись при приземлении; `expectedWorldVx/Vz` не пересчитывался после сброса, создавая ложные коллизии

**Решение:**
- [x] Полный сброс `vy = 0`, `fyActual[i] = 0`, `yawRate *= 0.5` при приземлении после длительного полёта (≥5 тиков)
- [x] Пересчёт `expectedWorldVx/Vz` после сброса
- [x] Добавлен debug HUD (`/realisticdebug`) для диагностики
- [x] Улучшенное прямолинейное демпфирование vy при отсутствии руля

## BUG-2: Резкая остановка при приземлении ✅ ИСПРАВЛЕНО
**Приоритет:** СРЕДНИЙ
**Статус:** Исправлено в Фазе 6.2
**Симптомы:** Машина теряет почти всю скорость при приземлении с прыжка
**Причина:** Vanilla `move()` клиппит горизонтальную скорость при столкновении с землёй
**Решение:** В `moveHook()` сохраняется горизонтальная скорость до `move()`. При приземлении (вертикальная скорость была отрицательной и стала больше) если потеря >30% — восстанавливается 85% в направлении движения. Стеновые коллизии отличаются по forward component <10%.
