# План реалистичного ралли — IBREALISTIC

> **Структура документа:** Завершённые фазы (1–5a) → Известные баги → Будущие фазы (6–16) с порядком зависимостей.
> Каждый шаг включает работу с переводами (lang/*.yml + triton.yml + triton/timingsystem.json).
> Функционал всегда реализуется **до** визуала: нельзя делать GUI без готового бэкенда.

---

## Порядок зависимостей между фазами

```
ФАЗА 6  (Баги и стабильность)      ← делать ПЕРВОЙ, без неё всё ненадёжно
   ↓
ФАЗА 7  (Версионирование серверов) ← нужно для совместимости клиент-сервер
   ↓
ФАЗА 8  (Экономика: валюта + XP + ежедневные задания) ← ✅ завершено
   ↓
ФАЗА 9  (Кастомизация автомобилей) ← зависит от экономики (покупки)
   ↓
ФАЗА 10 (Соло-рейсы без коллизий) ← зависит от кастомизации (выбор машины) + XP (уровни)
   ↓
ФАЗА 11 (Настройка треков: погода, время суток) ← зависит от соло-рейсов (нужны треки)
   ↓
ФАЗА 12 (Раллийные процедуры)     ← зависит от настроек треков
   ↓
ФАЗА 13 (Система поломок и износа) ← зависит от кастомизации + раллийных процедур
   ↓
ФАЗА 14 (Античит)                  ← зависит от всей физики и экономики
   ↓
ФАЗА 15 (Поддержка рулей и педалей)← независимо, но после стабилизации физики
   ↓
```

# ИЗВЕСТНЫЕ БАГИ И ПРОБЛЕМЫ 🐛

## BUG-1: Накопление воздушного состояния ✅ ИСПРАВЛЕНО
**Приоритет:** ВЫСОКИЙ — влияет на геймплей
**Статус:** Исправлено в Фазе 6.1
**Симптомы:**
- Первый прыжок проходит нормально (кроме резкой остановки при приземлении)
- Второй и последующие прыжки тянут машину в сторону
- Эффект накапливается: каждый следующий прыжок хуже предыдущего

**Причина:** `vy` и `fyActual[]` не обнулялись при приземлении; `expectedWorldVx/Vz` не пересчитывался после сброса, создавая ложные коллизии

**Решение:**
- [x] Полный сброс `vy = 0`, `fyActual[i] = 0`, `yawRate *= 0.5` при приземлении после длительного полёта (≥5 тиков)
- [x] Пересчёт `expectedWorldVx/Vz` после сброса
- [x] Добавлен debug HUD (`/realisticdebug`) для диагностики
- [x] Улучшенное прямолинейное демпфирование vy при отсутствии руля

## BUG-2: Резкая остановка при приземлении ✅ ИСПРАВЛЕНО
**Приоритет:** СРЕДНИЙ
**Статус:** Исправлено в Фазе 6.2
**Симптомы:** Машина теряет почти всю скорость при приземлении с прыжка
**Причина:** Vanilla `move()` клиппит горизонтальную скорость при столкновении с землёй
**Решение:** В `moveHook()` сохраняется горизонтальная скорость до `move()`. При приземлении (вертикальная скорость была отрицательной и стала больше) если потеря >30% — восстанавливается 85% в направлении движения. Стеновые коллизии отличаются по forward component <10%.

    - Поверхности (гравий/грязь изнашивает быстрее)
    - Стиля езды (блокировка колёс, резкие повороты)
    - Пресета шин (Soft = быстрый износ, Hard = медленный)
  - [ ] Визуальное уведомление: «⚠️ Шины изношены на 70%!»
  - [ ] Пакет `SET_TIRE_WEAR` (server → client)
  - [ ] Отображение в action bar: полоски износа каждой шины

### 13.2 Перегрев двигателя
- [ ] **Функционал (мод + плагин):**
  - [ ] Состояние: `engineTemp` (0.0–1.0, где 1.0 = перегрев)
  - [ ] Нагрев: при полном газе в течение 30+ секунд
  - [ ] Охлаждение: при отпускании газа, при низкой скорости
  - [ ] При перегреве: `engineForce × (1.0 - 0.5 × overheat)` (50% потеря мощности)

### 13.3 Повреждения от столкновений
- [ ] **Функционал (мод + плагин):**

  - [ ] Увеличивается при столкновении (пропорционально скорости удара)

    - `damage < 0.3`: нет эффектов
    - `damage 0.3–0.6`: снижение maxSteering на 10%, вибрация руля
    - `damage 0.6–0.8`: снижение engineForce на 20%, рывки
