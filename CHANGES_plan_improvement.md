# Изменения: Улучшение и расширение PLAN.md

2026-02-12

## Краткое описание
Полная переработка PLAN.md с добавлением новых фаз, детализацией каждого шага, указанием зависимостей между фазами, и включением переводов в каждый этап.

## Изменённые файлы

### Документация
- `PLAN.md` — полная переработка (275 → 1221 строк)

## Детальное описание изменений

### 1. Структурные улучшения
- Добавлена **диаграмма зависимостей** между фазами (что делать перед чем)
- Завершённые фазы (1–5a) **сжаты** — убраны детали реализации, оставлена суть
- Добавлен раздел **«Известные баги»** с подробным описанием и планом исправления
- Добавлен раздел **«Принципы разработки»** с правилами порядка реализации

### 2. Новые фазы
- **ФАЗА 6:** Баги и стабильность физики (BUG-1: накопление воздушного состояния, BUG-2: остановка при приземлении)
- **ФАЗА 7:** Кастомная система версионирования серверов (REALISTIC_SERVER_INFO, REALISTIC_CLIENT_INFO, feature flags)
- **ФАЗА 8:** Экономика и прогрессия (Vault, Rally Coins, XP/уровни, ежедневные задания)
- **ФАЗА 9:** Кастомизация автомобилей (пресеты компонентов, гараж, магазин, спавн)
- **ФАЗА 10:** Соло-рейсы без коллизий (изоляция, выбор машины, лидерборды, стартовая процедура)
- **ФАЗА 11:** Настройки треков (погода, время суток, динамическая погода, сложность)
- **ФАЗА 12:** Раллийные процедуры (старт, фальстарт, Time Controls, сервис-парк, Recce, мультиэтапное ралли)
- **ФАЗА 13:** Система поломок и износа (шины, двигатель, кузов, ремонт)
- **ФАЗА 14:** Античит (валидация скорости, конфигурации, экономики)
- **ФАЗА 15:** Поддержка рулей и педалей (GLFW, GUI настроек, Force Feedback)
- **ФАЗА 16:** Визуал и полировка (GUI магазина, гаража, профиля; VFX, звуки, HUD)
- **ФАЗА 17:** Бэклог дополнительных идей (достижения, турниры, ставки, replay, Discord)

### 3. Переводы в каждом шаге
- Каждый шаг каждой фазы теперь включает секцию **«Переводы»** с указанием конкретных ключей
- Указан порядок: en_us.yml → triton.yml → остальные lang файлы → triton/timingsystem.json

### 4. Детализация экономики
- **Vault** как провайдер + **Rally Coins** как внутренняя валюта
- SQL-схемы таблиц для монет и транзакций
- Формулы начисления (за треки, рекорды, лидерборды, ежедневные бонусы)
- Конфигурируемые награды через config.yml

### 5. Система уровней XP
- Прогрессивная формула XP
- Визуальное отображение через Minecraft XP bar
- Разблокировка машин и компонентов по уровням
- Таблица уровней: 1→LIGHTWEIGHT, 5→CLASSIC, 10→WRC, 15→GROUP_B, 20→TRUCK

### 6. Соло-рейсы
- Изоляция через hidePlayer() + NOCOL_BOATS_AND_PLAYERS
- Два лидерборда: SYSTEM (честное соревнование) и CUSTOM (свои машины)
- Стартовая процедура с обратным отсчётом и фальстартом
- SQL-схема для результатов

### 7. Настройки треков
- Погода (WeatherCondition) привязана к треку
- Время суток (player.setPlayerTime)
- Динамическая погода (опционально)
- Сложность (1-5 звёзд) с множителями наград

### 8. Версионирование серверов
- Пакеты REALISTIC_SERVER_INFO и REALISTIC_CLIENT_INFO
- Feature flags (bitfield) для гранулярной совместимости
- Graceful degradation при несовпадении версий

### 9. Баг воздушной физики
- Подробное описание симптомов накопления состояния
- 5 вероятных причин с указанием файлов и строк
- План диагностики и исправления
