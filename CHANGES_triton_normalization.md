## Детальное описание изменений

### 1. Нормализация Triton JSON (timingsystem.json)
**Файл:** `triton/timingsystem.json`
**Затронуто:** 369 из 397 записей

**Проблема:**
До изменения 340 из 397 записей имели несогласованные цветовые коды между языками:
- `en_GB`, `ru_RU`, `pl_PL` — не имели цветовых кодов (голый текст)
- `de_DE`, `nl_NL`, `es_ES`, `pt_BR`, `fr_FR` — имели цветовые коды, но не всегда одинаковые

Это означало, что при использовании Triton игроки с en/ru/pl получали белый неформатированный текст, а игроки с de/nl/es/pt/fr — форматированный.

**Решение:**
Все языки теперь используют одинаковые цветовые коды из en_us.yml (мастер-шаблон):
- `&e` — ошибки (красный)
- `&s` — успех (зелёный)
- `&w` — предупреждения (жёлтый)
- `&1` — основной (серый) — для меток и структуры
- `&2` — вторичный (белый) — для значений
- `&a` — награда (золотой) — для достижений
- `&c` — вторичная награда (жёлтый) — для подсветки
- `&b` — оповещение (аквамарин) — для трансляций
- `&t` — заголовок (тёмно-серый) — для заголовков GUI

**Примеры:**

До:
```
ts.error.generic:
  en_GB: "Something went wrong."          (нет цвета)
  ru_RU: "Что-то пошло не так."           (нет цвета)
  de_DE: "&eEtwas ist schiefgelaufen."    (есть &e)
```

После:
```
ts.error.generic:
  en_GB: "&eSomething went wrong."         (единый &e)
  ru_RU: "&eЧто-то пошло не так."         (единый &e)
  de_DE: "&eEtwas ist schiefgelaufen."     (единый &e)
```

### 2. Исправление цветов spawn-предметов
**Файлы:** Все YAML в `src/main/resources/lang/`

**Проблема:**
Spawn-предметы использовали vanilla цветовые коды Minecraft (`&6`, `&7`), которые НЕ поддерживаются MessageParser. Это приводило к тому, что коды отображались как литеральный текст.

**Решение:**
| Предмет | Было | Стало | Значение |
|---------|------|-------|----------|
| Tracks (название) | `&a` | `&s` | Зелёный (success) |
| Tracks (описание) | `&7` / `&2` | `&1` | Серый (primary) |
| Reset (название) | `&c` | `&e` | Красный (error) |
| Reset (описание) | `&7` / `&2` | `&1` | Серый (primary) |
| Boat (название) | `&6` / `&a` | `&s` | Зелёный (success) |
| Boat (описание) | `&7` / `&2` | `&1` | Серый (primary) |

## Категории обработки

### Простые сообщения (prefix-only)
~290 записей — один цветовой код в начале (`&eОшибка`, `&sУспех`, `&wПредупреждение`)

### Метка:Значение
~50 записей — `&1Метка: &2Значение` (серая метка, белое значение)

### Заголовки (title)
~20 записей — `&1--- &2Заголовок &1---` (серые разделители, белый текст)

### Оповещения (broadcast)
~10 записей — `&b--> Текст <--` (аквамариновый)

### Достижения (award)
~5 записей — `&cЛичный рекорд!` (жёлтый)

### Без форматирования
28 записей — hover-тексты, слова, кнопки (без цветов, цвет задаётся через Java)
