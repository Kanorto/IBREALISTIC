# Изменения: Исправление бокового ускорения при столкновениях и остановки при приземлении

## Дата
2026-02-12

## Краткое описание
Исправлены два бага в FourWheelPhysicsEngine: ложное боковое ускорение при столкновении с блоками и резкая остановка при приземлении с высоты.

## Изменённые файлы

### Мод (OpenBoatUtilsRealistic)
- `src/main/java/dev/o7moon/openboatutils/physics/FourWheelPhysicsEngine.java` — добавлена система обнаружения коллизий и защита от ложных боковых сил

## Детальное описание изменений

### 1. Collision-Aware Velocity Initialization (Защита от ложного бокового ускорения)
**Файл:** `FourWheelPhysicsEngine.java`
**Что сделано:**
- Добавлено отслеживание ожидаемой мировой скорости (`expectedWorldVx`, `expectedWorldVz`) между тиками
- При конвертации скорости из мировых координат в локальные, движок теперь сравнивает фактическую скорость сущности с ожидаемой
- Если обнаружена коллизия (значительная потеря скорости или изменение направления), боковая компонента скорости (vy) ограничивается через `MAX_COLLISION_LATERAL_INJECTION`
- Боковые силы шин уменьшаются на 50% при обнаружении коллизии для предотвращения накопления ложных сил

**Причина:**
Когда лодка сталкивается со стеной, Minecraft обрезает мировую скорость. При конвертации обрезанного вектора скорости в локальную систему координат машины, продольная скорость (vx) частично "перетекала" в боковую скорость (vy). Это создавало огромный угол скольжения и сильные боковые силы, выбрасывающие лодку с трассы.

### 2. Landing Inertia Preservation (Сохранение инерции при приземлении)
**Файл:** `FourWheelPhysicsEngine.java`
**Что сделано:**
- При переходе из воздуха на землю (`wasAirborne && !airborne`), боковая скорость (vy) демпфируется коэффициентом `LANDING_LATERAL_DAMPING` (0.5)
- Боковые силы шин также демпфируются для предотвращения резких боковых рывков
- Скорость вращения (yawRate) уменьшается на 20% при приземлении

**Причина:**
При приземлении с высоты коллизия с блоками обрезает скорость, а конвертация из мировых координат создаёт неправильное распределение скорости. Это вызывало резкую остановку вместо плавного продолжения движения с инерцией.

### 3. Новые константы
- `COLLISION_SPEED_LOSS_THRESHOLD = 0.3f` — порог обнаружения коллизии (30% потери скорости)
- `MAX_COLLISION_LATERAL_INJECTION = 1.5f` — максимальная боковая скорость, которую может "инжектировать" коллизия
- `LANDING_LATERAL_DAMPING = 0.5f` — демпфирование боковой скорости при приземлении
